How to turn a Microsoft Teams transcript into SRT subtitles

Updated 4 November 2026 · SubRip (.srt) and WebVTT (.vtt) · Türkçe

I record a meeting, want to put the video somewhere with subtitles, and hit the same wall every time: Teams hands me a .vtt file, but the video editor or LMS asks for .srt. The two formats are close cousins, so the fix is quick once you know the differences.

The short version

  • Teams lets meeting organizers download the transcript as .vtt from Recap → Transcript → Download.
  • SRT is almost the same as VTT: numbered cues, a comma before the milliseconds, and no WEBVTT header.
  • If you can open the recording page but can't download, Transcript Saver saves an .srt straight from the transcript panel.

What's the difference between VTT and SRT?

WebVTT (.vtt)SubRip (.srt)
First lineWEBVTTNo header
Cue numbersOptionalRequired: 1, 2, 3…
Time format00:01:02.50000:01:02,500
Speaker namesOften as <v Name> tagsPlain text, e.g. Name: …
Typical useWeb players, HTML5 videoVideo editors, YouTube, most LMSs

Method 1: Convert the Teams .vtt file yourself

  1. Download the transcript as .vtt from the meeting's Recap → Transcript → Download. This works if you organized the meeting or were given permission.
  2. Open the file in a plain text editor and delete the WEBVTT line at the top.
  3. Replace the dot before the milliseconds with a comma in every time line (00:00:05.120 --> 00:00:08.400 becomes 00:00:05,120 --> 00:00:08,400). An editor with find and replace makes this one step.
  4. Turn speaker tags like <v Ayşe Kaya> into plain text (Ayşe Kaya: ) and remove the closing </v>.
  5. Number the cues 1, 2, 3… with a blank line between them, and save the file with a .srt extension.

Free online VTT-to-SRT converters do steps 2–5 for you. Before you upload a work meeting to one, check your company's rules: the transcript leaves your computer.

Method 2: Save SRT from the recording page with Transcript Saver

This is what I use when there's no Download button for me, or I just don't want to edit timestamps by hand.

  1. Install Transcript Saver in Chrome or Edge.
  2. Open the meeting recording in the Stream / SharePoint player (the page ends in stream.aspx).
  3. Open the Transcript panel next to the video.
  4. Click SRT in the small Transcript Saver toolbar. The file lands in your downloads folder, with speaker names in front of each line.

One honest note: the transcript panel only gives the moment each line starts. Transcript Saver lets each subtitle run until the next line begins, up to 15 seconds, so timings are close but not frame-perfect. For meeting recordings that is usually all you need.

Questions people ask

Why does my video tool reject the Teams transcript file?

Teams exports WebVTT (.vtt), and many editors and learning platforms only accept SubRip (.srt). Convert the file or save it as SRT directly.

Can I get SRT if I wasn't the meeting organizer?

The Download button in Recap is usually limited to the organizer. If you can open the recording page and see the transcript, Transcript Saver can save it as SRT from there.

Will the SRT include speaker names?

Yes. Transcript Saver writes the speaker name before each line, for example "Ayşe Kaya: Let's start with the roadmap."

Does it work for meetings that weren't transcribed?

No. Transcription has to be turned on during the meeting; there is nothing to convert otherwise.
